# Retail Sales Analysis – Excel Project

## Project Overview
Analyzed retail sales data using Microsoft Excel to identify sales trends and business insights.

## Tools & Skills
- Microsoft Excel
- Sorting & Filtering
- Pivot Tables
- Excel Formulas
- Data Analysis

## Key Insights
- City-wise sales performance
- Top-selling products
- Payment method analysis
- Revenue analysis
- Business recommendations

## Objective
To understand sales performance and support better business decisions through data analysis.
